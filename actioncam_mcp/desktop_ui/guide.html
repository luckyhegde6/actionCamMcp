ActionCam MCP Studio — Visual & Workflow User Guide

End-to-end guide for connecting DJI Osmo Action 4 footage with DaVinci Resolve Studio 21, the Desktop UI, MCP tools, ACTIONCAM_SOUNDS_DIR audio mixing, and automatic exports/YouTube/ classification.

python run.py desktop   # Launch Desktop UI
python run.py mcp      # Start JSON-RPC 2.0 MCP Server
python run.py status   # Verify DaVinci Resolve Studio 21 connection

1 DaVinci Resolve Studio 21 Setup

  1. Open Preferences > System > General.
  2. Set External scripting using to Local and save.
  3. Open your project (e.g. test1) with timelines like Journey_Edit or Into_My_Cat.

2 DJI Action 4 D-Log M & LUTs

Use 10-bit D-Log M on the DJI Osmo Action 4. Resolve's API requires relative LUT paths:

DJI/DJI OSMO Action 4 D-Log M to Rec.709 V1.cube

Pair with CDL color grading (SetCDL) for warm sunrise (Journey_Edit) or vibrant pet tones (Into_My_Cat).

3 Default Audio Mixin (ACTIONCAM_SOUNDS_DIR)

AudioEngine scans actioncam_mcp/assets/sounds (or ACTIONCAM_SOUNDS_DIR) by default and routes ambience, whooshes, chimes, and BGM onto Fairlight tracks A1–A3.

  • Journey_Edit: Strips noisy camera audio and lays soothing ambience + reverb swells.
  • Into_My_Cat (Pintu): Adds intro chime, cut sweeps, and playful background bed.

4 Automatic Export Classification

ExportManager classifies renders into platform folders automatically:

  • exports/YouTube/ — YouTube - 1080p & youtube_4k
  • exports/Reels_Shorts/ — 9:16 vertical exports
  • exports/Master/ — DNxHR HQX archives
  • exports/Web_Preview/ — Lightweight review MP4s
